Flexible duct is fast to install and forgiving of misalignment, which is exactly why it is so often abused. Used as intended it is a tidy solution; used as a substitute for rigid ductwork it quietly wrecks system performance.

## What flexible duct is

Flexible duct, or "flex," is a coiled steel-wire helix supporting an inner liner, wrapped in fibreglass insulation and an outer vapour-barrier jacket. It comes compressed in a box and stretches out on site. Its appeal is obvious: it bends around obstructions, needs no fittings, and connects an offset duct to a ceiling diffuser in minutes.

That convenience hides a cost. The inner liner is never smooth — even fully stretched it has a slightly ribbed wall — and that texture, plus any bend, makes flex far more resistive to airflow than equivalent rigid metal duct.

## High friction loss

This is the single most important fact about flex duct: **it has much higher friction loss than rigid duct of the same diameter.**

Fully stretched and dead straight, a flex duct loses roughly two to three times the pressure per metre of a galvanised round duct at the same airflow. That is the best case. Real installations are worse, because flex is rarely fully stretched and rarely straight.

| Condition | Effect on resistance |
|---|---|
| Fully extended, straight | baseline for flex, already ~2 to 3x rigid |
| 4 percent longitudinal compression | resistance roughly doubles again |
| Sag between supports | adds bends and pooling, large penalty |
| Tight radius bend | severe local loss, can choke the run |

A run that the designer sized assuming smooth duct will deliver far less air if it is built in compressed, sagging flex. The fan cannot make up the difference, so the room is starved and the occupant complains.

## The damage done by poor installation

Three site habits destroy flex duct performance.

### Compression

Flex is often pulled from the box and connected without being stretched out. Leaving it even slightly compressed bunches the liner into a continuous series of ridges. As little as 4 percent compression — barely visible — can double the run's resistance. Flex should always be installed **fully extended**, then cut to the exact length needed, never left long and squashed in.

### Sag

An unsupported flex run droops between its end points. Each droop is effectively two bends and a low spot where the liner folds. Sag must be controlled with saddle supports of adequate width at regular intervals so the duct runs straight and level, not in a series of U-shapes.

### Tight bends

A sharp bend collapses the inner liner and crushes the airway. The bend radius should be generous — at least one duct diameter to the centreline, more is better — and bends should be gradual. A 90-degree turn made in a tight kink can lose more pressure than the entire straight run.

## Maximum recommended lengths

Because every metre of flex costs disproportionate pressure, runs must be kept short. A widely used guideline limits a flex connection to roughly **1.5 m (5 ft)** in normal duty and no more than about 2.4 m (8 ft) at the absolute outside, fully stretched. Some specifications cap it tighter. The principle is simple: the shorter the flex, the smaller the penalty you have designed around.

If the diffuser is far from the rigid duct, the answer is to extend the rigid duct closer, not to run a long tail of flex.

## Where flexible duct belongs and where it does not

Flex has one legitimate role: the **short final connection** between a rigid duct or a ceiling plenum box and a single supply or return diffuser. In that role it lets the ceiling grid be set out independently of the ductwork above, absorbs minor misalignment, and is quick to fit.

It should **never** be used for:

- main supply or return trunks
- branch runs serving several outlets
- any long horizontal run
- anything carrying medium or high pressure

Using flex for a main run combines the worst of every problem above — high baseline friction, multiplied by compression, sag and bends over a long length — and the fan simply cannot overcome it. The result is a noisy, under-performing system that no amount of balancing can rescue.

Treat flex as a short, fully stretched, gently routed tail. Keep it under about 1.5 m, support it so it does not sag, give it a generous bend radius, and use rigid duct for everything else.
